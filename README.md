# 🗂️ Task Management Dashboard (Vanilla JS)

A role-based task management web application built using **HTML, Tailwind CSS, and Vanilla JavaScript**.

This project was created to strengthen my understanding of frontend architecture, state management, filtering, and dynamic rendering before transitioning into modern frameworks like React and Next.js.

---

## 🚀 Features

### 👨‍💼 Admin Dashboard

* Assign tasks to multiple users
* Set due dates
* Sort tasks by:

  * Earliest
  * Latest
* Filter tasks by:

  * All
  * Overdue
  * Near Due
  * Normal
* Review submitted proofs
* Approve or reject tasks

### 👤 User Dashboard

* View assigned tasks
* Submit proof of completion
* Resubmit proof if rejected
* View:

  * Pending tasks
  * Approved tasks
  * Rejected tasks
* Automatic sorting on page refresh
